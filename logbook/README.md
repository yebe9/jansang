# Ghosting · 비공개 움직임 기록함

[개인 기록함 열기](https://ghosting-logbook.jansang.workers.dev/logs/)

한 명의 소유자가 개인 비밀번호로 여는 기록함이다. 원본 움직임 영상과 내 의도, 실제 AI 응답·오류, 후보 적합도·근거를 함께 보관하고 비교한다. 공개 Ghosting의 방문자 영상을 자동으로 수집하지 않는다. 비밀번호 없이는 기록 저장·목록·상세·영상 조회가 모두 불가능하다.

## 기록을 남기는 순서

1. [Ghosting](https://yebe9.github.io/jansang/) 또는 로컬 `http://127.0.0.1:4173/`에서 새 기록을 시작한다.
2. 원본 영상이 필요하면 촬영 전에 설정의 **이번 움직임의 영상도 보관**을 켠다. 기본값은 꺼짐이며 지난 기록을 나중에 영상으로 복원하지는 못한다. 기존 카메라 스트림의 영상 트랙만 복제하므로 소리는 녹음하지 않는다. 얼굴과 주변 환경이 포함될 수 있다.
3. 결과 팝업에서 의도·AI 결과를 확인하고 **비공개 로그에 저장**을 누른다. 영상 보관을 선택하지 않아도 의도·결과만 저장할 수 있다.
4. 새 로그 창에서 개인 비밀번호로 로그인한다. 이미 로그인한 상태라면 이 단계는 자동으로 통과한다.
5. 원래 결과 화면에서 요청한 기록이 바로 Cloudflare 저장소에 업로드된다. 두 화면의 **저장 완료** 표시를 확인한다. 실패하면 받은 자료를 유지하고 원인과 재시도 버튼을 표시한다. 촬영 종료만으로는 저장되지 않는다.

로그 창을 새로고침해도 원래 결과 화면이 열려 있으면 같은 ID로 기록을 다시 받아 중복 없이 저장한다. 두 창을 모두 닫거나 원래 화면에서 새 기록을 시작하면 미저장 자료가 사라질 수 있다. 이전 버전의 링크로 연 로그 창은 미리보기의 **이 기록 저장하기** 버튼으로 저장할 수 있다.

기록을 열어 영상을 재생하고, JSON 또는 영상으로 내려받거나 삭제할 수 있다. 삭제에는 확인 창이 나온다. 목록의 미완료 기록도 삭제할 수 있으며, 같은 ID를 다시 저장해도 이미 저장된 내용은 덮어쓰지 않는다.

로그인 세션은 최대 12시간이다. 로그인이 만료되면 화면의 영상과 기록을 숨기고 다시 로그인하도록 안내한다. 소유자 전용 비밀번호는 이 작업 환경의 `.codex-preview/logbook-owner-access.txt`에서 따로 관리한다. 그 파일과 비밀번호를 Git·ZIP·발표 자료에 포함하지 않는다.

## 분석을 읽는 방법

- 대표 인상과 내 의도를 나란히 보고, 영상에서 해당 표현의 근거를 찾아본다.
- 후보는 AI가 실제로 보고한 최대 5개다. 적합도 0–100은 비보정 보고값이며 확률·정확도·모델 내부의 실제 후보 순위가 아니다. 합계가 100일 필요도 없다. 미보고 수치는 0으로 채우지 않는다.
- 대표 인상과 최고 적합도 후보가 다르면 원문을 바꾸지 않고 차이를 알린다.
- **기록 정보 보기**에서 표현 선택 기준의 수치를 확인할 수 있다. `유연한`에는 전신 관절의 굽힘·펴짐 근거가 필요하고, `유려한`에는 충분히 긴 구간의 안정된 이동이 필요하다. 이는 2D 좌표에 대한 경험적 기준으로, 신체 가동 능력이나 감정을 측정한 결과가 아니다. 미측정값은 0과 구분한다.
- **자주 남은 인상**은 저장 완료된 대표 표현의 빈도다. 다양한 표현을 억지로 나오게 하거나 감정 분포를 추정하려는 기능이 아니다.

50개 표현의 시각적 정의와 수치 기준은 [`api/expression-rubric.mjs`](../api/expression-rubric.mjs)에 있다. 기준을 충족해도 AI가 해당 표현을 반드시 선택하는 것은 아니다. 기록을 비교하면서 근거의 적절성과 기준의 한계를 검토한다.

## 저장 범위와 한도

| 항목 | 저장 위치·방식 |
| --- | --- |
| 선택한 원본 영상 | Cloudflare KV, 로그인한 소유자만 API로 조회 |
| 의도·상세 설명·AI 결과·후보·수치·오류 | Cloudflare D1 |
| 로그인 세션 | D1에 토큰 해시와 만료 시각, 브라우저에는 Secure·HttpOnly·SameSite=Strict 쿠키 |
| 비밀번호 | 서버에는 PBKDF2 해시와 salt를 비밀 값으로 등록 |

영상당 **15 MiB**, 영상 합계 **500 MiB**, 기록 **500개**가 앱에서 정한 상한이다. Cloudflare 서비스 자체의 할당량은 별도로 적용된다. 새 영상은 KV의 지역 간 반영 때문에 잠시 열리지 않을 수 있다. 영상 다시 열기를 사용하고, 계속 실패하면 목록을 다시 확인한다.

공개 API에서 로그인·업로드 성공, 비로그인 목록·영상 요청의 401 차단, 영상 범위 요청의 206 응답, 삭제·로그아웃을 확인했다. 실제 춤을 촬영한 영상의 품질이나 모든 브라우저의 녹화 호환성을 검증한 것은 아니다.

**로그 서버에 저장하는 것과 Gemini에 보내는 것은 다르다.** Gemini에는 관측 좌표·움직임 수치만 보내며 원본 영상·얼굴 좌표·음성·내 의도·상세 설명은 보내지 않는다. 영상 보관을 선택했더라도 결과의 저장 버튼을 눌러 로그인한 로그 창에 전달하기 전에는 이 브라우저의 임시 데이터다.

## 구성과 유지 관리

- `public/index.html`, `public/app.js`, `public/styles.css`: 로그인·저장 전 검토·목록·영상·결과 화면.
- `worker.mjs`: 인증, 저장·삭제, 영상 범위 요청 처리와 한도 검사.
- `schema.sql`: 기록·세션 테이블.
- `wrangler.toml`: 전용 Worker, D1·KV 바인딩과 요청 빈도 제한.
- [`dist/session-recorder.js`](../dist/session-recorder.js): 선택한 영상의 브라우저 녹화.

공개 화면은 `/logs/`, 정적 파일은 `/app.js`, `/styles.css`에 있다. 창 사이 자료 전달은 인증 후에만 시작하며, 로그 창은 실제 opener와 `https://yebe9.github.io`, `http://127.0.0.1:4173`, `http://localhost:4173` 출처를 확인한다. 임의의 창이 보내는 자료를 받지 않는다. 세션 만료 후에는 다시 로그인해야 하며 저장은 항상 별도 버튼으로 확인한다.

이 Worker는 AI API와 별도로 배포한다. 등록된 Cloudflare 계정에서 코드 변경을 반영할 때 프로젝트 루트에서 다음을 실행한다.

```powershell
npx wrangler deploy --config logbook/wrangler.toml
```

현재 D1·KV와 인증 비밀 값이 등록된 배포용 설정이다. 다른 계정에 새로 설치하려면 그 계정의 저장소와 비밀 값을 따로 준비해야 한다. `.env`, `.dev.vars`, `.codex-preview/`, `.wrangler/`, 비밀번호 파일을 제출물에 넣지 않는다. 제출 ZIP에는 이 폴더의 소스·스키마·공개 설정·문서만 포함한다.
